# Настройка modelseek — коротко

Подробности в [README.md](README.md). Здесь — путь от нуля до работающего поиска.

## 1. Запуск

| Система | Что сделать |
|---|---|
| Windows | поставить Python 3.10+ (галочка «Add python.exe to PATH»), дважды кликнуть `start.bat` |
| Linux | `sudo apt install python3 python3-venv` (или аналог), затем `./start.sh` |
| Docker | `docker compose up -d --build` |

Откроется http://127.0.0.1:8088 — это **админский профиль**. Он работает только с этого компьютера.

Автозапуск: Windows — `autostart.bat`, Linux — `./install-service.sh`, Docker запускается сам.

## 2. Первая настройка в интерфейсе

Всё ниже делается в *Настройки* (шестерёнка справа вверху) и сохраняется сразу, без правки файлов:

1. **Источники** — включите нужные сайты и вставьте бесплатные ключи (Thingiverse, Cults3D, MyMiniFactory).
2. **Внешний вид** — тема и размер карточек.
3. **Ранжирование** — веса по умолчанию, фильтры, склейка дублей.
4. **Перевод и смысл**, **Компоненты** — по желанию: перевод запросов через Ollama, смысловой поиск,
   браузерный режим.
5. **Подписки и уведомления** — Telegram, ntfy или свой адрес.

Куда это сохраняется:

| Что | Где |
|---|---|
| настройки из интерфейса | `data/settings.yaml` (перекрывает `config.yaml`; «Сбросить всё» в *Сервер* возвращает к нему) |
| ключи и пароли | `data/secrets.env` или `.env` (значение из `.env` важнее) |
| избранное, история, подписки | `data/modelseek.db` |
| тема и последние фильтры поиска | браузер (localStorage) |

В Docker папка `data/` — это том `modelseek_modelseek-data`. Пересборка его не трогает, а `docker compose down -v`
и удаление тома в Docker Desktop стирают его вместе с ключами. Ключи надёжнее держать в `.env`, резервная копия
данных описана в README.

Только в `config.yaml`, не через интерфейс: путь к своему Chrome (`browser.executable_path`),
`server.allowed_hosts`, `server.data_dir` и весь раздел `public`. Так чужая страница не сможет их поменять.

## 3. Доступ с телефона и других устройств (по желанию)

Для этого есть **внешний профиль**: отдельный порт, только поиск. Избранное, история, подписки, ключи
и настройки владельца там недоступны. Гость хранит свои настройки в куки, а избранное — в своём браузере.

1. Откройте `config.yaml`, найдите раздел `public` и поставьте:

   ```yaml
   public:
     enabled: true
     port: 8090
     auth: password        # или none, или subnet
   ```

2. Для `auth: password` задайте пароль: *Настройки → Сервер → Внешний профиль → Пароль для гостей*.
   Для `auth: subnet` перечислите сети: `allow_from: [192.168.1.0/24]`.
3. Перезапустите modelseek. В консоли появится строка `внешний профиль: 0.0.0.0:8090`.
4. С телефона откройте `http://<адрес-компьютера>:8090`. Адрес на Windows — `ipconfig`, на Linux — `ip a`.
   Возможно, порт 8090 придётся разрешить в брандмауэре.

В Docker внешний порт по умолчанию открыт только на этом компьютере. Чтобы зашли другие устройства, добавьте
в `.env` строку `MODELSEEK_PUBLIC_BIND=0.0.0.0` и выполните `docker compose up -d`. В Docker Desktop адреса
гостей не видны, поэтому `auth: subnet` и `allow_from` там не подходят — используйте `auth: password`.

Гости ищут со своими ключами API (*Настройки → Ключи сайтов* в их браузере), ключи владельца им не выдаются.
Чтобы гость без ключа искал с ключом владельца, поставьте `public.lend_keys: true`.

Через интернет — только за reverse proxy с HTTPS (Caddy, nginx), его адрес впишите в `public.trusted_proxies`.

## 4. Если что-то не так

| Признак | Что делать |
|---|---|
| «Сервер не отвечает» | modelseek не запущен — запустите `start.bat` / `start.sh` |
| порт 8088 занят | `MODELSEEK_PORT=9000` перед запуском или в `.env` |
| ошибка в `config.yaml` при запуске | текст ошибки называет ключ, например `public.auth` — исправьте и перезапустите |
| гость видит «доступ с этого адреса закрыт» | его адреса нет в `public.allow_from` (в Docker Desktop адреса не видны — уберите `allow_from`) |
| у гостя источник «нет ключа» | гость вводит свой ключ в *Настройки → Ключи сайтов* или в `config.yaml` включается `public.lend_keys: true` |
| у источника «нет ключа» | *Настройки → Источники*, вставьте ключ |
