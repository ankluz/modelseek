# Настройка modelseek

Краткий путь от установки до работающего поиска. Подробности — в [README.md](README.md).

## 1. Запуск

| Система | Действие |
|---|---|
| Windows | установить Python 3.10+ (отметка «Add python.exe to PATH») и запустить `start.bat` |
| Linux | `sudo apt install python3 python3-venv` (или аналог для дистрибутива), затем `./start.sh` |
| Docker | `docker compose up -d --build` |

Интерфейс открывается по адресу http://127.0.0.1:8088 — это **админский профиль**, доступный только с этого компьютера.

Автозапуск: Windows — `autostart.bat`, Linux — `./install-service.sh`, в Docker контейнер перезапускается автоматически.

## 2. Первая настройка в интерфейсе

Все параметры ниже находятся в *Настройки* (шестерёнка справа вверху) и сохраняются сразу, без правки файлов:

1. **Источники** — включение сайтов и бесплатные ключи (Thingiverse, Cults3D, MyMiniFactory).
2. **Внешний вид** — тема и размер карточек.
3. **Ранжирование** — веса по умолчанию, фильтры, склейка дублей.
4. **Перевод и смысл**, **Компоненты** — перевод запросов через Ollama, смысловой поиск, браузерный режим.
5. **Подписки и уведомления** — Telegram, ntfy или webhook.

Где хранятся данные:

| Данные | Место |
|---|---|
| настройки из интерфейса | `data/settings.yaml` (перекрывает `config.yaml`; «Сбросить всё к config.yaml» в разделе *Сервер* отменяет изменения) |
| ключи и пароли | `data/secrets.env` или `.env` (значение из `.env` имеет приоритет) |
| избранное, история, подписки | `data/modelseek.db` |
| тема и последние фильтры поиска | браузер (localStorage) |

В Docker папка `data/` — это том `modelseek_modelseek-data`. Пересборка его сохраняет, а `docker compose down -v`
и удаление тома в Docker Desktop удаляют его вместе с ключами. Ключи надёжнее хранить в `.env`; резервная копия
данных описана в README.

Только в `config.yaml`, без доступа из интерфейса: путь к Chrome (`browser.executable_path`), `server.allowed_hosts`,
`server.data_dir` и раздел `public`. Сторонняя страница не может изменить эти параметры.

## 3. Доступ с телефона и других устройств

Для этого служит **внешний профиль**: отдельный порт только с поиском. Избранное, история, подписки, ключи
и настройки владельца в нём недоступны. Настройки гостя хранятся в куки, избранное — в его браузере.

1. В `config.yaml`, в разделе `public`, задайте:

   ```yaml
   public:
     enabled: true
     port: 8090
     auth: password        # или none, или subnet
   ```

2. Для `auth: password` задайте пароль в *Настройки → Сервер → Внешний профиль → Пароль для гостей*.
   Для `auth: subnet` перечислите сети: `allow_from: [192.168.1.0/24]`.
3. Перезапустите modelseek. В консоли появится строка `внешний профиль: 0.0.0.0:8090`.
4. На телефоне откройте `http://<адрес-компьютера>:8090`. Адрес компьютера показывает `ipconfig` (Windows)
   или `ip a` (Linux). Порт 8090 может потребоваться открыть в брандмауэре.

В Docker внешний порт по умолчанию доступен только на этом компьютере. Доступ для других устройств открывает
строка `MODELSEEK_PUBLIC_BIND=0.0.0.0` в `.env` и перезапуск `docker compose up -d`. Docker Desktop скрывает
адреса гостей, поэтому `auth: subnet` и `allow_from` там не работают; для Docker подходит `auth: password`.

Гости ищут со своими ключами API (*Настройки → Ключи сайтов* в их браузере), ключи владельца им не выдаются.
Поиск с ключом владельца для гостей без своего ключа включает `public.lend_keys: true`.

Доступ через интернет — только через reverse proxy с HTTPS (Caddy, nginx); его адрес указывается
в `public.trusted_proxies`.

## 4. Решение проблем

| Признак | Решение |
|---|---|
| «Сервер не отвечает» | modelseek не запущен — запустите `start.bat` / `start.sh` |
| порт 8088 занят | `MODELSEEK_PORT=9000` перед запуском или в `.env` |
| ошибка в `config.yaml` при запуске | текст ошибки называет ключ, например `public.auth`; исправьте его и перезапустите |
| гость видит «доступ с этого адреса закрыт» | его адреса нет в `public.allow_from` (в Docker Desktop адреса не видны — уберите `allow_from`) |
| у гостя источник «нет ключа» | гость вводит ключ в *Настройки → Ключи сайтов*, либо в `config.yaml` включается `public.lend_keys: true` |
| у источника «нет ключа» | введите ключ в *Настройки → Источники* |
