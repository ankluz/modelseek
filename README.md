# modelseek

<img src="frontend/favicon.svg" width="64" alt="">

Локальный поисковик 3D-моделей по нескольким сайтам: общий интерфейс, прозрачное ранжирование, темы оформления,
избранное, подписки на запросы и поиск по картинке через внешние сервисы.

**Источники:** Printables, MakerWorld, Thingiverse, Thangs, Cults3D, MyMiniFactory, собственные источники с JSON API,
сайты из SearXNG и сайты-ссылки (Yeggi, GrabCAD, CGTrader…).

**Профили:** админский — http://127.0.0.1:8088, доступен только с этого компьютера и содержит все настройки;
внешний — отдельный порт только с поиском для других устройств, по умолчанию выключен.

Краткая инструкция по установке и настройке — [SETUP.md](SETUP.md).

## Установка

| Способ | Особенности |
|---|---|
| [Windows без Docker](#windows-без-docker) | браузерный режим с окном проверки, автозапуск при входе в Windows |
| [Linux без Docker](#linux-без-docker) | браузерный режим, автозапуск через systemd |
| [Docker (Windows и Linux)](#docker-windows-и-linux) | изолированная среда, одинаковая на обеих ОС; браузерный режим недоступен |

### Windows без Docker

1. Установите **Python 3.10 или новее** с https://www.python.org/downloads/.
   В первом окне установщика отметьте **«Add python.exe to PATH»**.
2. Распакуйте modelseek в любую папку, например `C:\Users\<имя>\modelseek`.
3. Запустите **`start.bat`**. При первом запуске скрипт:
   - создаёт окружение `.venv` и устанавливает зависимости (нужен интернет, 1–2 минуты);
   - копирует `.env.example` в `.env`;
   - запускает сервер и открывает http://127.0.0.1:8088.

   Сервер работает, пока открыто окно консоли. Остановка — `Ctrl+C` или закрытие окна.
4. Следующий шаг — [первая настройка](#первая-настройка).

Дополнительно:

- **Модули** браузерного режима, смыслового поиска и других функций устанавливаются в *Настройки → Компоненты*.
  Если установка из интерфейса не проходит, используется `install-extras.bat`.
- **Автозапуск при входе в Windows** нужен для проверки подписок без открытого окна: `autostart.bat`.
  modelseek запускается в фоне, журнал пишется в `data\modelseek.log`. Отключение: `autostart.bat remove`.

### Linux без Docker

1. Установите Python 3.10+ и модуль venv:
   - Debian / Ubuntu: `sudo apt install python3 python3-venv`
   - Arch / CachyOS: `sudo pacman -S python`
   - Fedora: `sudo dnf install python3`
2. Распакуйте modelseek и запустите:

   ```bash
   cd modelseek
   chmod +x start.sh install-extras.sh install-service.sh
   ./start.sh
   ```

   Скрипт создаёт `.venv`, устанавливает зависимости, копирует `.env.example` в `.env` и открывает
   http://127.0.0.1:8088 (при наличии `xdg-open`). Другой порт: `MODELSEEK_PORT=9000 ./start.sh`.
3. Следующий шаг — [первая настройка](#первая-настройка).

Дополнительно:

- **Модули** — *Настройки → Компоненты* или `./install-extras.sh`. Chromium для браузерного режима требует
  системных библиотек; скрипт выводит команду их установки для Debian / Ubuntu и Arch.
- **Автозапуск через systemd** нужен для проверки подписок: `./install-service.sh` создаёт пользовательский
  сервис `modelseek.service`. Статус: `systemctl --user status modelseek`, журнал: `journalctl --user -u modelseek -f`.
  Работа без входа в систему: `sudo loginctl enable-linger $USER`.

### Docker (Windows и Linux)

Образ modelseek — Linux-контейнер. На Linux он работает напрямую, на Windows — в Docker Desktop через WSL 2.
Образ и `docker-compose.yml` одинаковы для обеих ОС, различается только установка Docker:

- **Windows:** установите [Docker Desktop](https://www.docker.com/products/docker-desktop/) с включённым WSL 2,
  перезагрузите компьютер и запустите Docker Desktop. Команды ниже выполняются в PowerShell.
- **Linux:** установите Docker Engine и плагин Compose (команда `docker compose version` должна работать).
  Arch / CachyOS: `sudo pacman -S docker docker-compose && sudo systemctl enable --now docker`,
  затем `sudo usermod -aG docker $USER` и повторный вход в систему.

Запуск из папки modelseek:

```bash
docker compose up -d --build
```

Интерфейс открывается по адресу http://127.0.0.1:8088. Данные хранятся в томе Docker — см. «Данные и ключи» ниже.

| Задача | Команда |
|---|---|
| SearXNG для поиска по другим сайтам | `docker compose --profile web up -d` |
| Ollama для перевода запросов | `docker compose --profile ollama up -d`, затем *Настройки → Перевод и смысл → Скачать модель* |
| Образ без curl_cffi, fastembed и Pillow | `MODELSEEK_EXTRAS=0 docker compose build` (PowerShell: `$env:MODELSEEK_EXTRAS=0; docker compose build`) |
| Другой порт | `MODELSEEK_PORT=9000` в окружении или в файле `.env` рядом с `docker-compose.yml` |
| Доступ с других устройств | [внешний профиль](#доступ-с-других-устройств) в `config.yaml`; порт на компьютере — `MODELSEEK_PUBLIC_PORT` (8090) |
| Журнал | `docker compose logs -f modelseek` |
| Остановка | `docker compose down` (данные сохраняются; `down -v` удаляет и их) |
| Резервная копия данных | `docker compose cp modelseek:/app/data ./modelseek-backup` (копия содержит ключи и не предназначена для публикации) |
| Восстановление из копии | `docker compose cp ./modelseek-backup/. modelseek:/app/data`, затем<br>`docker compose exec -u root modelseek sh -c "chown -R modelseek: /app/data; chmod 600 /app/data/secrets.env"`<br>и `docker compose restart modelseek` |

Особенности Docker:

- **Данные и ключи** хранятся в томе `modelseek_modelseek-data`, а не в папке `data/`. Том сохраняется при
  `docker compose up -d --build`, `docker compose down` и перезапуске Docker Desktop. Удаляют том
  `docker compose down -v`, удаление в Docker Desktop (*Volumes → Delete*) и *Troubleshoot → Clean / Purge data*.
  Ключи из `.env` рядом с `docker-compose.yml` от тома не зависят и имеют приоритет над сохранёнными в интерфейсе.
- **Браузерный режим** (`mode: browser`) в контейнере недоступен: окну проверки негде открыться.
  Режим `impersonate` работает.
- **Компоненты** curl_cffi, fastembed и Pillow входят в образ, кроме сборки с `MODELSEEK_EXTRAS=0`.
  Playwright в образ не входит.
- **Ollama вне контейнера:** в *Настройки → Перевод и смысл* указывается адрес `http://host.docker.internal:11434/v1`.
  На Linux Ollama должна слушать не только localhost: `OLLAMA_HOST=0.0.0.0` в её настройках.
- **Windows:** папка modelseek может лежать на диске Windows или внутри WSL. `config.yaml` подключается
  в контейнер только для чтения.

### Первая настройка

1. Откройте http://127.0.0.1:8088 и выполните поиск, например `gridfinity`. Printables работает без настройки,
   MakerWorld и Thangs показываются ссылками в строке «Искать также на…».
2. **Ключи API** (бесплатные) вводятся в *Настройки → Источники*, в полях «Токен», «API-ключ» и «Логин»:
   - Thingiverse: https://www.thingiverse.com/apps/create → Desktop app → App Token
   - Cults3D: https://cults3d.com/en/api/keys (логин — ник на Cults3D)
   - MyMiniFactory: https://www.myminifactory.com/settings/developer
3. Карточки MakerWorld и Thangs требуют компонента playwright или curl_cffi (*Настройки → Компоненты*)
   и режима `browser` или `impersonate` (*Настройки → Источники*). Подробнее — [режимы источников](#режимы-источников).
4. Тема оформления выбирается в *Настройки → Внешний вид*.

### Обновление

- Без Docker: замените файлы новой версией, сохранив папки `.venv` и `data`, и запустите `start.bat` / `./start.sh`;
  скрипт установит новые зависимости.
- Docker: замените файлы и выполните `docker compose up -d --build`.

Новая версия может изменить `config.yaml`. Изменения из интерфейса хранятся отдельно, в `data/settings.yaml`,
и при обновлении сохраняются.

### Решение проблем

| Признак | Решение |
|---|---|
| `start.bat`: «Python 3.10+ not found» | переустановите Python с отметкой «Add python.exe to PATH» |
| `start.sh`: не создаётся `.venv` | Debian / Ubuntu: `sudo apt install python3-venv` |
| Порт 8088 занят | `MODELSEEK_PORT=9000` перед запуском |
| Чип источника «ошибка» | причина видна в подсказке при наведении; при «доступ запрещён» нужен ключ или режим `browser` |
| Чип «пауза» | источник три раза подряд ответил ошибкой и отключён на 10 минут; кнопка ↻ включает его сразу |
| Режим browser: «не установлен playwright» | *Настройки → Компоненты* или `install-extras` |
| Docker на Windows: `docker: command not found` | запустите Docker Desktop и откройте новый терминал |

## Возможности

### Режимы источников

| Режим | Работа |
|---|---|
| `http` | обычные HTTP-запросы; для официальных API (Thingiverse, Cults3D, MyMiniFactory) и Printables |
| `link` | сайт не опрашивается, в строке «Искать также на…» появляется ссылка; режим по умолчанию для MakerWorld и Thangs |
| `impersonate` | запрос с TLS-отпечатком Chrome (модуль curl_cffi) |
| `browser` | Chromium (модуль playwright); при проверке на бота появляется кнопка «Пройти проверку», которая открывает окно браузера для ручного прохождения |

`impersonate` и `browser` обходят защиту сайтов от ботов, что обычно нарушает их правила. modelseek рассчитан
на личное использование: небольшое число запросов, без массового сбора данных.

### Поиск по картинке

Кнопка с камерой у строки поиска. Картинку (файл, перетаскивание, вставка из буфера или ссылка) ищут внешние
сервисы: **Google Lens, Яндекс Картинки, Bing Visual Search**. Картинка отправляется напрямую в выбранный сервис,
результат открывается в новой вкладке; modelseek картинку не сохраняет. Фото больше 1600 px уменьшаются перед
отправкой.

Кнопка «Похожие по картинке» на карточке запускает тот же поиск по превью модели.

Поиск по форме для 3D-файлов (STL, 3MF) есть на Thangs; диалог содержит ссылку на него.

### Смысловой поиск (дополнительный модуль)

Локальная мультиязычная модель (~220 МБ, работает на процессоре) добавляет в рейтинг сигнал «смысловая
близость»: «держатель наушников» ≈ «headphone holder». Требует модуля fastembed и включается в
*Настройки → Перевод и смысл*.

### Перевод запросов

Русские запросы переводятся на английский через OpenAI-совместимый API: Ollama, LM Studio или облачный сервис.
В *Настройки → Перевод и смысл* есть кнопки установки Ollama (Windows — winget, macOS — brew), её запуска
и загрузки модели. На Linux установщик Ollama требует `sudo`, поэтому интерфейс показывает команду для терминала.

### Рейтинг

```
score = Σ вес_сигнала · сигнал  ×  вес_источника
```

| Сигнал | Значение |
|---|---|
| Совпадение слов | доля слов запроса в названии (с учётом словоформ) и тегах плюс нечёткое сходство |
| Смысловая близость | только с модулем fastembed |
| Позиция на сайте | место модели в выдаче самого сайта |
| Популярность | `log(лайки + 0.3·скачивания + 3·makes)`, нормированная внутри каждого сайта |
| Свежесть | экспоненциальное затухание с периодом полураспада |
| Похоже на избранное | авторы и теги из избранного |

Недоступные сигналы исключаются, веса остальных перенормируются. Нажатие на балл в карточке открывает его разбивку.

**Темы над выдачей** уточняют неоднозначный запрос: для «hornet» это «hollow knight», «super hornet», «hornet trap».
Нажатие на тему оставляет только её, «−» исключает.

**Склейка дублей:** одна модель с разных сайтов показывается одной карточкой со ссылками вида «+ Thingiverse».

### Фильтры и пресеты

Фильтры: цена (бесплатно / платно / до N €), минимум лайков, скачиваний и печатей, период публикации, лицензия
(разрешена ли продажа печати), обязательные и исключённые слова, скрытые авторы, только с превью, без уже открытых.
Встроенные пресеты: «Проверенные», «Свежие (30 дней)», «Бесплатные и популярные», «Можно продавать печать»,
«Без мусора», «Новое для меня». Текущие фильтры сохраняются как собственный пресет.

### Избранное, подписки, уведомления

- ♡ на карточке добавляет модель в коллекцию; вкладка «Избранное» содержит коллекции и заметки.
- «Подписаться» сохраняет запрос с фильтрами. Периодичность — от раза в час до раза в неделю или произвольное
  число минут. Первый успешный ответ каждого сайта сохраняется как исходная выдача, после этого подписка
  показывает только новые модели. Модели сайта, который был недоступен, не считаются новыми после его возвращения.
  Если сайт поддерживает сортировку, подписка запрашивает самые новые модели.
  Проверки выполняются, пока modelseek запущен (см. автозапуск).
- Уведомления: ntfy, Telegram или webhook — *Настройки → Подписки и уведомления*.

### Собственные источники

*Настройки → Свои источники → Добавить источник*: адрес API с подстановками `{q}`, `{limit}`, `{offset}`,
`{page}`, `{page0}`, метод GET или POST, путь к массиву моделей и поля. Кнопка «Проверить» показывает массивы
в ответе, поля первого элемента (назначаются нажатием) и превью карточек. В том же разделе настраиваются
сайты-ссылки для строки «Искать также на…».

## Доступ с других устройств

Админский профиль открывается только с этого компьютера: он слушает `127.0.0.1` и отклоняет запросы с других
адресов и через прокси. Для телефона, ноутбука или гостей предназначен **внешний профиль** — отдельный порт
в том же процессе, с общим кэшем и теми же источниками.

Внешний профиль содержит поиск, фильтры, веса, темы, а также избранное и пресеты гостя. Эти данные хранятся
в браузере гостя: настройки поиска и тема — в куки, избранное, история и скрытые модели — в локальном хранилище.
Избранного, истории, подписок и ключей владельца, установки компонентов и настроек сервера во внешнем профиле нет:
соответствующих адресов на внешнем порту не существует. Запросы гостей не попадают в историю владельца.

Профиль включается в `config.yaml` (не через интерфейс) и требует перезапуска:

```yaml
public:
  enabled: true
  port: 8090
  auth: password          # none | password | subnet
  allow_from: []          # например [192.168.1.0/24]; для auth: subnet обязательно
```

| `auth` | Доступ |
|---|---|
| `none` | все, кому доступен порт (с учётом `allow_from`) |
| `password` | по общему паролю. Пароль задаётся в *Настройки → Сервер → Внешний профиль* или переменной `MODELSEEK_PUBLIC_PASSWORD`; смена пароля завершает сеансы всех гостей |
| `subnet` | только адреса из `allow_from` |

Дополнительные ограничения: число поисков в минуту с одного адреса (`searches_per_minute`), число одновременных
поисков (`max_parallel_searches`) и список источников для гостей (`sources`). Собственные источники владельца
в локальной сети гостям не показываются. После пяти неверных паролей подряд вход с адреса закрывается на 10 минут.

**Гости ищут со своими ключами.** Ключи API владельца гостям не выдаются. Гость вводит ключи в *Настройки → Ключи
сайтов*; они хранятся в куки его браузера и передаются на сервер только вместе с поиском. Сайт, для которого у гостя
нет ключа, пропускается; `public.lend_keys: true` разрешает таким гостям искать с ключом владельца. Ошибки с ключом
гостя не ставят источник на паузу в админском профиле.

Сайты, разрешающие запросы со сторонних страниц (CORS), браузер гостя опрашивает напрямую, со своим ключом и со
своего адреса; сервер только разбирает и ранжирует ответ. Такой ответ предназначен одному гостю, не попадает в кэш,
а ссылки в нём проверяются так же, как остальные. Из встроенных источников так работает MyMiniFactory. Printables,
Thingiverse и Cults3D запрещают запросы из браузера, поэтому их поиск для гостей идёт через сервер. Если сайт
не ответил браузеру, поиск тоже идёт через сервер.

Внешний порт рассчитан на недоверенных посетителей: тело запроса — до 4 КБ, заголовки — до 16 КБ, запрос должен
прийти целиком за 10 секунд, с одного адреса — до 24 соединений. Медленные и зависшие соединения не занимают
сервер, и админский профиль продолжает отвечать.

Доступ через интернет — только через reverse proxy с HTTPS: по обычному HTTP пароль и ключи гостя передаются
открытым текстом. Адрес прокси указывается в `public.trusted_proxies`, чтобы лимиты считались по настоящему IP гостя.

**Docker.** Внешний порт по умолчанию доступен только на этом компьютере. Доступ для других устройств открывает
строка `MODELSEEK_PUBLIC_BIND=0.0.0.0` в `.env` и перезапуск `docker compose up -d`. Docker Desktop передаёт
контейнеру все подключения с одного адреса — своего шлюза, поэтому лимиты считаются по браузеру (случайный номер
в куки), а для гостей без куки действует общий лимит. `allow_from` и `auth: subnet` в Docker Desktop не пропускают
гостей, потому что их адреса не видны. Для проверки по адресам modelseek запускается без Docker.

## Конфигурация

Слои настроек, каждый следующий перекрывает предыдущий:

1. значения по умолчанию в коде;
2. `config.yaml`, который правится вручную;
3. переменные окружения `MODELSEEK__РАЗДЕЛ__КЛЮЧ` (например, `MODELSEEK__TRANSLATE__URL`); через них Docker
   задаёт адреса сервисов;
4. `data/settings.yaml` — изменения из интерфейса. Значение `null` удаляет ключ из `config.yaml`.

Ключи API хранятся в переменных окружения: в `.env` (его читают `start.bat`, `start.sh` и Docker) или
в `data/secrets.env` (его пишет интерфейс). `config.yaml` содержит только **имена** переменных.

### Справочник `config.yaml`

| Ключ | По умолчанию | Значение |
|---|---|---|
| `server.cache_ttl_seconds` | 900 | сколько секунд хранить ответы сайтов в памяти |

## Разработка

На Windows окружение активируется командой `.venv\Scripts\activate` вместо `. .venv/bin/activate`.

```bash
python -m venv .venv && . .venv/bin/activate
pip install -r requirements-dev.txt
pytest -q
python -m app.serve                         # оба профиля, как в скриптах запуска
uvicorn app.main:app --reload --port 8088   # только админский профиль, перезагрузка при изменениях
```

Встроенный источник — класс в `app/sources/` с методом `search(fetcher, query, limit, page)`, строка в `REGISTRY`
(`app/sources/__init__.py`) и секция в `config.yaml`. `fetcher` выбирается по `mode`, поэтому источник работает
во всех режимах. Для сайтов с собственной сортировкой задаётся `native_sorts` (сортировка modelseek → значение
сайта), а `search` принимает аргумент `sort`.

API: `GET /api/search/stream?q=…` (SSE), `GET /api/search`, `/api/sources`, `/api/settings`,
`/api/favorites`, `/api/subs`, `/api/presets`, `/api/history`, `/api/extras`, `/api/ollama`, `/api/jobs/{id}`.
Изменяющие запросы принимаются только с заголовком `X-Modelseek: 1`.

## Безопасность

Админский профиль слушает только `127.0.0.1` и отвечает только этому компьютеру; запросы с других адресов
и через прокси отклоняются. В Docker порт публикуется только на `127.0.0.1`, а контейнер отвечает только шлюзу
Docker, поэтому соседние контейнеры в той же сети получают отказ. Админский профиль устанавливает программы
и записывает ключи, поэтому:

- запросы принимаются только на разрешённые адреса (`server.allowed_hosts`), что закрывает DNS rebinding;
- API не отвечает на запросы с других сайтов, а изменяющие запросы проверяют `Origin`;
- путь к браузеру, `allowed_hosts` и `data_dir` не меняются через API;
- токен перевода и уведомлений из интерфейса нельзя взять из ключа сайта или системной переменной — только
  из ключей, сохранённых в настройках или в `.env`; в `config.yaml` имя переменной задаётся без этой проверки;
- изменяющие запросы требуют заголовок `X-Modelseek: 1`, который сторонняя страница в браузере отправить не может.

Во [внешнем профиле](#доступ-с-других-устройств) нет ни одного адреса, который меняет настройки или читает
данные владельца.

### Защита от сайтов, на которых идёт поиск

Ответы сайтов считаются недоверенными. modelseek:

- не обращается во внутреннюю сеть (роутер, NAS, `169.254.169.254`, сам modelseek) — ни по перенаправлению,
  ни за превью, ни из страницы в режиме browser. Адрес проверяется после разрешения DNS, поэтому имена вроде
  `evil.test → 127.0.0.1` тоже блокируются;
- обращается к локальным адресам только там, где они указаны в настройках: SearXNG, Ollama, адрес уведомлений,
  собственный источник. Сторонний сайт не может перенаправить запрос даже на них;
- не передаёт ключи и заголовки источника другому сайту при перенаправлении и проходит не больше 5 перенаправлений;
- читает не больше 8 МБ ответа (4 МБ для картинки при склейке дублей), в том числе после распаковки gzip,
  и не раскрывает картинки больше 40 Мп;
- приводит результаты к безопасному виду: только ссылки http(s), ограниченная длина названия, автора и тегов,
  без бесконечных и отрицательных чисел и без невидимых символов для подмены текста;
- отдаёт страницу со строгим CSP (только собственные скрипты, запросы только к modelseek),
  `Referrer-Policy: no-referrer` и запретом встраивания в сторонние страницы;
- в режиме browser блокирует скачивание файлов и service worker'ы, а WebRTC не раскрывает локальный адрес.

Превью моделей браузер загружает напрямую с сайтов, поэтому сайты видят его IP-адрес, как при обычном посещении.

Шрифты интерфейса — Orrery Text (производный от Jost\*) и Orrery Gauge для логотипа и заголовков, оба под
SIL Open Font License 1.1. Они лежат в `frontend/fonts` вместе с текстом лицензии `OFL.txt`; сторонние сервисы
шрифтов не используются.
