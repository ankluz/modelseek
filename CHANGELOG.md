# Изменения

## 1.0.0 — 2026-11-06

Первая стабильная версия.

### Поиск

- Один поиск по Printables, MakerWorld, Thingiverse, Thangs, Cults3D, MyMiniFactory, своему SearXNG
  и своим источникам; результаты приходят по мере ответа сайтов.
- Рейтинг по релевантности, популярности, свежести, весу источника, смыслу запроса (fastembed)
  и сходству с избранным; склейка дублей, в том числе по картинкам.
- Фильтры, пресеты, перевод запроса на английский через Ollama, поиск по картинке.
- Избранное с коллекциями, скрытие моделей и авторов, история, подписки на запросы с уведомлениями.
- Режимы источников: http, impersonate (curl_cffi), browser (Playwright с окном проверки) и link.

### Два профиля

- Админский профиль открывается только с этого компьютера; в Docker он отвечает только шлюзу Docker.
- Внешний профиль (`public` в config.yaml) — для телефона и гостей: только поиск, всё личное гостя
  хранится в его браузере. Вход без пароля, по общему паролю или по подсетям.
- Гости ищут со своими ключами API; ключи владельца выдаются только при `public.lend_keys: true`.
  MyMiniFactory браузер гостя опрашивает сам, со своего адреса.
- Лимиты для гостей: поиски в минуту, попытки пароля, размер запросов, медленные соединения.
  В Docker Desktop лимиты считаются по браузеру.

### Защита

- Ответы сайтов считаются недоверенными: запросы во внутреннюю сеть блокируются, размеры ответов ограничены,
  ссылки и текст очищаются.
- Строгий CSP, проверка Origin и Host, изменяющие запросы принимаются только с заголовком `X-Modelseek`.
- Ключи записываются в `secrets.env` атомарно и с правами 600; ошибка записи показывается в интерфейсе.

### Прочее

- Шрифты Orrery Text и Orrery Gauge (SIL OFL 1.1) лежат в проекте, сторонние сервисы шрифтов не используются.
- Лицензия AGPL-3.0; ссылка «Исходный код» отдаёт архив кода этой установки, в том числе из Docker.
- Установка на Windows и Linux, Docker с компонентами по умолчанию, автозапуск, краткая инструкция SETUP.md.
- В Docker данные и ключи хранятся в томе; README описывает резервную копию и восстановление,
  а настройки предупреждают, что том стирает `docker compose down -v`.
